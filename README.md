# PontoFácil

Sistema simples de controle de ponto desenvolvido para praticar desenvolvimento web com HTML, CSS e JavaScript.

O projeto permite visualizar o horário atual e registrar os horários de entrada e saída de um funcionário, exibindo os registros no histórico do dia.

## Tecnologias

* HTML5
* CSS3
* JavaScript

## Objetivo

Projeto desenvolvido como parte dos meus estudos de JavaScript, com foco em manipulação do DOM, eventos, datas e criação dinâmica de elementos na página.
